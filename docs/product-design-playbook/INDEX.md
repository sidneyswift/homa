# Product Design Playbook source archive

This archive preserves all 206 PDF pages as extracted text plus readable full-page screenshots. It is the canonical source for Homa's repository Product Design Playbook skill; it is not the skill itself.

## Archive layers

- [Extracted framework](FRAMEWORK.md), the source's operating model,
  strategy-to-play structure, measurement loop, Homa boundaries, and cautions
- [Modular play catalog](CATALOG.md), normalized definitions and companion
  links for all 33 plays
- [Scoring contract](SCORING.md), fit-weighted flow scoring, evidence,
  outcomes, readiness, and portfolio eligibility
- [Extraction audit](AUDIT.md), completeness checks and confirmed source
  anomalies
- [Welcome and setup](welcome-and-setup.md), pages 1-5
- `strategies/`, 12 strategy modules with play stacks, metrics, and diagnostic questions
- `plays/`, 33 modular plays with guidance, reflection prompts, and three visual examples each
- `source/pages/`, one Markdown transcription for every PDF page
- `screenshots/`, one full-page JPEG for every PDF page
- `source/page-manifest.tsv`, a machine-readable completeness map
- `source/raw-reading-order.txt` and `source/raw-layout.txt`, uncurated extraction fallbacks
