The first ten days

The short version. Each moment explains one new way to use Homa, once.

Day 0 · signup

Start the text thread

After Family, one card names the four ways to reach Homa. On a phone, the button opens a ready-to-send text. On a computer, the code opens the same draft. After the parent taps Send, Homa replies with a phone contact to save.

After all children are added, Homa asks one question about one child. A parent who skipped the text receives Homa's automatic welcome after continuing. Only one welcome is sent.
Day 0 · report

Connect email, text, and the website

The report email says, "Reply to this email and Homa answers, just like chat." Website signups learn they can text Homa. Text signups learn what email and the website keep.

Day 1 · morning

Explain the first weekday-morning idea

The first weekday-morning idea says Homa will send one useful idea each weekday morning. Homa shares the idea for this child. Then she asks one easy question. That opening line never appears again.

Homa starts no more than one new topic a day during the first week. Replies continue normally.
Day 2 · mailbox

Put Homa on the fridge

A handwritten note arrives in the mail. A small code on the back opens a ready-to-send text. Homa asks text signups whether they want the note mailed.

If they say yes, Homa asks for their mailing address in the next text.
Around day 7 · one text

Explain what email and the website keep

"You can also find your reports in email. Each weekday morning I text one useful idea about your kids. The website keeps everything I make for you."

One message explains what email and the website keep. It never repeats.
Later · when the parent needs it

Invite the parent when the website solves a real need

Near evaluation season: "Everything Emma did this year is in her binder. You can sign in with the same Gmail you gave me. The binder lets you print it all at once."

The website invitation waits until the parent needs the binder.

What Homa remembers so introductions never repeat

This stores nothing about the kids. It is a tiny checklist of which adult has already learned about texting, email, the website, and calls.

Introductions tracked per parentOne parent's welcome does not mark the other parent's welcome as sent.
Introductions tracked per contact methodText, email, the website, and calls each get one introduction at the right moment.

Build order

Build the pieces in this order so we can measure each change before adding more texts.

  1. Measure today. Among families who connect a phone, how many text Homa within seven days? Compare the three days when the phone contact was broken with the days after it was fixed.
  2. Add the signup explanation. Add the plain texting details under the phone field. Add the phone button and computer code. Add the one-time introduction checklist. Remove the duplicate phone contact during text signup.
  3. Connect the report to the other ways to reach Homa. Add the email P.S. Show a different short block based on whether this family started on the website or by text.
  4. Explain the first weekday-morning idea. Add the one-time opening line to the first weekday-morning idea. Keep it in the same message.
  5. Put Homa on the fridge. Put the ready-to-text code on the back of the handwritten note. Ask text-first families whether they want one mailed, then ask for their address if they say yes.
  6. Explain what email and the website keep. Send one message around day seven. Mention the website again only when it solves a real need.
  7. Review one week of real numbers. Look separately at families who answered Homa's question and families who later started a new conversation themselves. Then decide whether connected families should also get report links by text. Email remains the permanent copy.

What we are not building

No long HOMA tourOne simple card appears after Family and before Kids. It has four short explanations and one Continue button.
Nothing to add to Apple Wallet or Google WalletIt does not make a Messages thread say "Homa." Saving Homa as a phone contact does.
No report texts before the first week's numbersWe will not add another Homa-started text until families show us the morning texts are welcome.
Three numbers tell us whether this worked

Early sign: how many families with a phone number answer Homa's first question? Main success: how many later start a new conversation themselves? Safety check: how many reply STOP? Starting a new conversation is the strongest proof that the parent understood and wanted to use texting.

The plan

Homa gives the parent something useful first. She asks one question after she knows the child. Each way to reach Homa gets one plain explanation. After that, Homa stays available without repeating herself.
