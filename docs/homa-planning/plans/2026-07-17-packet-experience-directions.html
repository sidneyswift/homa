Several pages, one PDF: what should packets feel like?

A real family asked for four weekly lessons as one PDF at midnight and got a print-and-staple apology. The pipeline fix already shipped (packets render, preview, and review page by page). This lab compares four product shapes for where packets go next. Same fake family, same task in every direction: get the four reading weeks as one file, print it, and set up the weeks ahead.

Every person, child, material, and metric here is fake (the Rivera family, Milo, age 5). No real family data is loaded, and no product code or route was changed by this page. Buttons marked "concept" simulate behavior that is not built.
Shipped today (live) create_printable builds multi-page packets (fresh pages + existing materials by id, 12-page cap), per-page previews, page-by-page quality review, card and Binder pagers.
The Binder exists /app/binder shows finalized materials with kind and subject chips; packets appear there with a page count. Only finals land in it, and nothing in it can be combined today.
Programs are the real ask The family that hit this asked for a 36-week program. Weekly bundles multiply the packet moment by 9; the planner and schedules exist but know nothing about materials.
Compile is deterministic Combining existing PDFs needs no model call. A merge could run as a plain server action from any surface, not only through a chat turn.

Where this is wrong

Five calls that change what gets built

1 · Should the Binder compile packets without a chat turn?

Yes means a new server merge action and a "gather" mode in the Binder UI (direction 2's core). No means every packet flows through Homa in chat, one code path, but she waits on words for something deterministic.

2 · Do weekly program packets build themselves on a schedule?

Auto-build (direction 4) needs a schedule kind, program state, and quality gating good enough to run unattended. On-ask keeps trust but keeps the weekly chore hers.

3 · Does a packet of 3+ pages get a cover page by default?

A cover (child's name, week list) makes the packet feel like a made thing and helps the fridge-door moment, but it is one more page of ink for some families.

4 · Where does a packet open when she taps it in the Binder?

The current overlay is cheap and already shipped (pager included). A dedicated page (direction 3's book) gives contents, grow actions, and a shareable URL, but adds a route and more state.

5 · Is 12 pages the right ceiling for one PDF?

12 keeps renders fast and files light; a whole 36-week program ships as volumes. Raising it to 20+ means fewer files for big units but slower builds and heavier previews.
