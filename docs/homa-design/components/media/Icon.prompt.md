Renders a Lucide icon, Homa's canonical icon set (rounded, 1.75 stroke). Requires the Lucide CDN script on the page.

```jsx
<Icon name="sparkles" size={20} />
<Icon name="book-open" size={24} color="var(--brand)" />
```

Use for all UI glyphs; never hand-draw SVGs. Common names: `sparkles`, `book-open`, `graduation-cap`, `chart-line`, `calendar`, `pencil`, `heart`.
