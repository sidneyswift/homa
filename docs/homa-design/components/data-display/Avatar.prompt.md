Circular avatar for kids, parent, or Homa. Shows photo if `src`, else initials on a warm auto-color.

```jsx
<Avatar name="Maya R" size={44} />
<Avatar name="Mom" src="/mom.jpg" />
```

Color derives from the name so each child stays consistent.
