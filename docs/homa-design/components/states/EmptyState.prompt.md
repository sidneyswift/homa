Empty state as a warm invitation, never a dead end. Homa always offers the next step.

```jsx
<EmptyState
  icon={<Icon name="calendar" size={24} />}
  title="Nothing planned yet"
  body="Tell me how this week looks and I'll draft a schedule around it."
  action={<Button iconLeft={<Icon name="sparkles" size={16} color="#fff" />}>Draft my week</Button>}
  hand="no rush ✎"
/>
```

Copy pattern: state the fact gently, then offer help in Homa's voice.
