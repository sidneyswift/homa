Playful divider under section headings: a short wave that settles into a thin rule.

```jsx
<h2>Featured this week</h2>
<Squiggle style={{ maxWidth: 360 }} />
<Squiggle color="var(--pop-cobalt)" segments={4} line={false} />
```

One per section heading, max. Use ink (default) on light bands; white on dark.
