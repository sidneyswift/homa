# Project rules

- **No em dashes, ever.** Never use the em dash character (U+2014) or `&mdash;` anywhere in this project: not in UI copy, code comments, docs, card names, or chat replies. Use a comma, a period, a colon, or a mid-dot (`·`) separator instead. This is a hard brand rule for Homa.
- **Brand name casing.** Write **Homa**, always, every place the name is typed. Never type **HOMA**. The logo is the logo: render the real `Logo` component (its wordmark spells "Homa"), never hand-typed letters standing in for it. Founder correction 2026-07-28 (`brand-casing-homa`), retiring global D8's old "HOMA on UI surfaces" wording. Code identifiers like `HomaDesignSystem_5e2305` stay as generated.
