# Project rules

- **No em dashes, ever.** Never use the em dash character (U+2014) or `&mdash;` anywhere in this project: not in UI copy, code comments, docs, card names, or chat replies. Use a comma, a period, a colon, or a mid-dot (`·`) separator instead. This is a hard brand rule for Homa.
- **Brand name casing.** In copy the name is written **Homa** (title case), never all-caps HOMA. The wordmark/logo renders **Homa** with a capital H. The only all-caps exception is text styled by an uppercase treatment (eyebrows, mono labels). Code identifiers like `HomaDesignSystem_5e2305` stay as generated.
