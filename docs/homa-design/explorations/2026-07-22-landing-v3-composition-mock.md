# Landing v3 composition mock (2026-07-22)

`2026-07-22-landing-v3-composition-mock.html` is a self-contained,
founder-approved landing page composition study from the /world
experiment (branch history: claude/homa-landing-v2-companion, plan docs
docs/homa-planning/plans/2026-07-21-world-v2-plan.md and
2026-07-21-world-v2-beats.md). Fonts and images are inlined; open the
file in any browser, no server needed.

What it establishes, independent of the scroll-video experiment:

- Contained media on the cream page, never full-bleed photos. Real
  product UI is the proof: a coded report card, a practice page, a
  rendition of the Your week planner, a morning note.
- Photos are small tilted chips layered on card corners, so nothing
  renders above its native pixels.
- Text position varies per beat: above the hero phone, beside the
  report, above the planner, inside the night panel.
- One living character: the logo mark itself (solid clay orange, no
  limbs), one instance per scene, with a job in every shot. Blink and
  bob animations respect reduced motion.
- Copy passed both gates (homa-copy-reviewer, then homa-copy-editor) on
  2026-07-22: Homa is the only "she" on the page, the child is always
  "your child", one name per concept, the report's data source answered
  in its own beat. Fixture child is Maya, the public demo child.

The founder marked this worth keeping as a landing design in its own
right, even if the scroll-scrubbed video format is not used.
