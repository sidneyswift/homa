# Agent-led Live Progress Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an agent-first child progress system where journal evidence and resumable check-ins update one live subject → domain → topic projection immediately.

**Architecture:** `ChildProgress` becomes the deep module around an append-only evidence ledger, conflict policy, live projection, and compatibility writes. `ProgressCheckIn` is a durable workflow inside that module. Existing `child_answers`, `child_reports`, scoring, and token reports remain compatible while in-app Progress receives a new live read model.

**Tech Stack:** TypeScript, Node test runner through `tsx`, postgres.js, Supabase Postgres and RLS, Next.js 16 App Router, React 19, Eve tools/instructions, Homa core scorer and taxonomy.

**Design contract:** `docs/superpowers/specs/2026-07-11-agent-led-live-progress-design.md`

**Status:** Production rollout completed on 2026-07-12. Deployment
`dpl_CVSe24nqdAHa5PdKhJJTUF97XSoS` is READY, the additive migration and
reconciliation completed, production isolation passed, and the feature flag is
enabled. Public, token-report, service, synthetic check-in, and temporary
authenticated Progress probes passed. A real linked-family SMS provider probe
remains open.

**Git constraint:** Do not create commits unless the user explicitly requests one.

**Workspace constraint:** Implement in the current non-main branch because the working tree contains uncommitted multi-parent and conversation-continuity prerequisites. Do not overwrite or discard unrelated changes.

- [ ] **Step 3: Implement the minimal policy**

```ts
import type { MapAnswer } from "@homa/core";

const ACTIVITY_ONLY_PATTERNS = [
  /\b\d+\s*(minutes?|hours?)\b.*\b(read|math|science|school)/iu,
  /\bwe (did|worked on|practiced|studied)\b/iu,
] as const;

const CONCRETE_SKILL_PATTERNS = [
  /\b(read|wrote|counted|solved|retold|explained|built|pedaled|swam)\b/iu,
  /\b(can|cannot|can't|could|without help|by themself|on their own)\b/iu,
] as const;

export function isProgressEvidenceAnswer(answer: MapAnswer): boolean {
  return answer === "easily" || answer === "getting_there" || answer === "not_yet";
}

export function classifyJournalEvidence(
  quote: string,
): "activity_only" | "concrete_skill" | "unclear" {
  if (ACTIVITY_ONLY_PATTERNS.some((pattern) => pattern.test(quote))) return "activity_only";
  if (CONCRETE_SKILL_PATTERNS.some((pattern) => pattern.test(quote))) return "concrete_skill";
  return "unclear";
}
```
