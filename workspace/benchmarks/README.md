# Benchmarks Library

> 🤖 MAINTAINED BY HOMA — updated nightly by the `your child Research Nightly` cron.

Each domain file is a citation-backed reference Homa uses to score your child's current position and set targets. Sources rotate based on the domain (CDC + ASQ-3 for motor/social, Common Core PreK + Core Knowledge for academics, Montessori for practical life, etc. — see each file).

## Files

- `math.md` — numeracy, counting, cardinality, geometry, measurement
- `literacy.md` — pre-reading, vocabulary, comprehension
- `phonics.md` — phonemic awareness, decoding
- `writing-fine-motor.md` — handwriting, pencil grip, scissors
- `spanish.md` — L2 vocabulary, comprehension, production
- `science.md` — life, physical, earth/space, inquiry
- `social-studies.md` — community, geography, cultures
- `art-creative.md` — drawing, painting, art appreciation
- `gross-motor.md` — running, balance, ball skills
- `fine-motor-general.md` — beyond writing — practical life
- `social-emotional.md` — emotion regulation, peer play, empathy
- `self-care-independence.md` — dressing, feeding, hygiene
- `executive-function.md` — attention, working memory, self-control
- `language-oral-english.md` — vocabulary, sentences, narrative
- `music.md` — rhythm, pitch, instrument exposure

## Conventions

Each file has these sections:
1. **Frameworks used** — which standards/research the benchmarks draw from
2. **Age-band milestones** — what's typical at 3y0m, 3y6m, 4y0m, 4y6m, 5y0m
3. **your child-specific notes** — observations, interests, hooks
4. **Recent research** — links to anything Homa learned this month
5. **Last researched** — date the cron last touched this file

When the cron updates a file, it logs the change in `~/.openclaw/workspace/research-journal.md`.

## your child's target

Default philosophy: **12 months ahead, balanced.** Your child's age determines which targets pull from the 4y0m–5y0m bands. Equal investment across all 15 domains; no over-specialization.
