# Homa Improvements Ledger

The self-improvement record. Every entry is a change to **Homa's own machinery** (skills, routing,
checks, scripts, rules) — grounded in a *specific observed friction*, not generic best-practice.
Written by the `homa-system-reflect` skill (weekly + on demand). See `skills/homa-system-reflect/SKILL.md`.

Status values: `proposed` (waiting on approval) · `applied` (done this session) · `embodied` (now a
permanent check/rule that prevents recurrence) · `rejected` (with reason, so it isn't re-proposed).
