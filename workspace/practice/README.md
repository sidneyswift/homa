# Practice Library

> 🤖 MAINTAINED BY HOMA — updated nightly by the `Nightly Research` cron, alongside the child-development `benchmarks/` library.

These files capture Homa's evolving knowledge about **the practice of homeschooling** — methodology, learning science, teaching techniques, curriculum reviews, parent sustainability, recent research, news, and local resources. Unlike `benchmarks/`, these aren't tied to any specific child's age and aren't used to score their position. They feed Homa's general wisdom that flows into weekly plans, activity suggestions, and conversations with parents.

## Files

- `pedagogy-methods.md` — Charlotte Mason, Montessori, classical, Reggio, Waldorf, unschooling, project-based — one approach per pass
- `learning-science.md` — how young kids retain, attention spans by age, motivation, scaffolding (ZPD), retrieval practice, spaced repetition
- `teaching-techniques.md` — effective questioning, wait time, productive struggle, growth-mindset feedback, math talk, read-aloud craft
- `curriculum-reviews.md` — evaluating Dimensions PKA / Heggerty / HWT / Science Fusion + alternatives Homa hasn't compared
- `tools-and-apps.md` — apps/games/software for homeschool, AI tools for parents
- `coop-and-social.md` — group learning dynamics, multi-age co-ops, peer interaction at 3–5
- `parent-sustainability.md` — routines, burnout signs, doing-less-better, spousal collaboration
- `recent-research-studies.md` — fresh papers in early childhood ed (PubMed, ERIC) — rotating sub-focus
- `homeschool-news-policy.md` — what's changing in the field, especially DC requirements
- `local-resources.md` — Location-agnostic guide to finding local homeschool resources (libraries, museums, co-ops, nature programs, compliance portals).

## Conventions per file

1. **Sources / frameworks** — what Homa is anchoring to
2. **Current understanding** — distilled state of knowledge (not raw notes)
3. **Open questions** — what Homa wants to learn next
4. **Recent research** — links + 1-line summaries from the last few passes
5. **Application to your family** — what's actually relevant to this family
6. **Last researched** — date stamp

When a file is updated, log the change in `~/.openclaw/workspace/research-journal.md`.
