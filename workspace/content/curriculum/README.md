# content/curriculum/

CURATED per-program working files — one folder per named curriculum (e.g. Dimensions-Math-PKA,
Hegg-Phonics, HWT, Science-Fusion, Art-Everywhere, co-op…), 1:1 with a vault `Curriculum/` page.
Grade progression is an **edition swap**, not a new folder: `dimensions-math/{pka,pkb,ka}/` siblings
with a `current` symlink — never `-v2/`. The level lives in the name + the freshness banner, not a date path.
