# content/

The child's homeschool, organized **for Homa** (not a vault mirror). Two halves + capture/fun/compliance:

| folder | role | scaling |
|---|---|---|
| `curriculum/<subject>/` | the **library** — book `source/` + `worksheets/`, by subject | **compounds**; reused across kids |
| `learners/<child>/` | the **cursor** — where each kid is + `what-works.md` (how they learn) | **flows**; one per child, `_TEMPLATE/` to add kid #2 |
| `sources/` | raw immutable captures (ToC photos, screenshots, lesson transcripts) | append-only |
| `fun/` | delight-first books/coloring/rewards (not a subject) | — |
| `compliance/` | state-report capture (dormant until compulsory age) | — |
| `finance/` | curriculum spend (stub until a real receipt) | — |

The Obsidian vault is a **rendered view** of this — the parent's binder shows `curriculum/` + its
`worksheets/`, and nothing she doesn't use. **Filing rules + the anti-clutter law: [`content/AGENTS.md`](AGENTS.md).**
Read `learners/<child>/what-works.md` before suggesting anything for that child.
