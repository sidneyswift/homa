# Character Descriptions for Image Prompts

Use these exact descriptions in every prompt for consistency. Do NOT use specific ages.

## Children

_Add your children's descriptions here during onboarding. Keep the description frozen across all pages of a book._

Example format:
```
a young boy character with shoulder-length wavy blonde hair and bright blue eyes, pale skin, rosy cheeks
```

> ⚠️ **NB2 Safety Filter:** Never use specific ages ("3-year-old boy") + physical descriptions — triggers 422. Use "a young boy/girl character with [features]" instead.

## Pets

_Add family pets here._

Example:
```
a small white French Bulldog puppy with a black patch over one eye and big bat ears
```

## Stuffed Animals / Toys

_Add the child's favorite stuffed animals here. Use their NAMES in stories — kids know them by name._

Example format:

| Name | Description |
|------|-------------|
| Mr Cow | white and gray plush cow with pink nose and small horns |
| Candy | pink Squishmallow bear with sparkly ears |
