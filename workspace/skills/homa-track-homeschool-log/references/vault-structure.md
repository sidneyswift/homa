# Obsidian Vault Structure

Vault path: `~/Documents/<vault>`

```
<vault>/
├── Home.md              ← landing page
├── index.md             ← catalog of everything (maintain this)
├── log.md               ← chronological record of vault changes
├── the-child.md         ← compiled learner profile
├── Subjects/            ← compiled knowledge per subject
│   ├── Math.md
│   ├── Spanish.md
│   ├── Phonics.md
│   ├── Writing.md
│   ├── Art.md
│   ├── Science.md
│   └── Social Studies.md
├── Curriculum/          ← per-curriculum guides & progress
│   ├── Dimensions-Math-PKA.md
│   ├── Hegg-Phonics.md
│   ├── HWT.md
│   └── Science-Fusion.md
├── Lessons/             ← daily logs (YYYY-MM/ subfolders)
├── Activities/          ← tested activity ideas
├── Sources/             ← raw immutable originals (photos, curriculum pages)
├── Weekly-Plans/        ← drafted weekly plans
├── Resources/           ← links, books, tools
└── Templates/           ← daily log template, etc.
```

## Rules

- **Always cross-link** between lessons, subjects, and curriculum pages
- **Sources/ is immutable** — drop raw photos there, reference from wiki pages
- **Update log.md** when adding or significantly updating a page
- **Update index.md** when creating new pages or sections
