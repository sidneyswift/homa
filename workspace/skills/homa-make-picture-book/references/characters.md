# Character Descriptions for Image Prompts

Use these exact descriptions in every prompt for consistency. Do NOT use specific ages.

## The child (main character)

```
a young boy character with shoulder-length wavy blonde hair and bright blue eyes, pale skin, rosy cheeks
```

## Bruno (cousin)

```
a young boy character with short brown hair and brown eyes, light brown skin, round cheeks
```

## Amalea (friend)

```
a young girl character with dark hair
```

## Reference Photos

Photos in `reference-images/<child>/`, `reference-images/stuffed-animals/`, `reference-images/family/`.
Upload to fal storage with `fal_client.upload_file()` before passing to the edit endpoint.
