# Subject → Curriculum Source Map

Maps each co-op subject the parent teaches to the file in `content/curriculum/co-op/` it draws from. Update this when a
subject is added or a curriculum file is renamed.

| Subject (as the co-op names it) | Primary source file | What to pull |
|---|---|---|
| **Phonics** (morning literacy) | `content/curriculum/co-op/22-week-literacy-curriculum.md` | Letter sequence (S,A,T → digraphs → CVC, 22 wks), 3-segment block (Circle Time / Sensory Letter / Dry-Erase), sensory rotation, materials, books & songs |
| **Science & Nature** | `content/curriculum/co-op/22-week-science-curriculum.md` | Weekly themes, Indoor Intro book + demo, Outdoor Exploration + guiding questions, poem recitation, materials |
| **Sensory** | `content/curriculum/co-op/22-week-science-curriculum.md` (Sensory Activity block) | The 12:30–12:45 hands-on sensory bin tied to each week's science theme (Mystery Bag, Soil & Seed, Animal Wash, Nature Soup, …) + sensory materials list |
| **Art** (if listed) | `content/curriculum/co-op/22-week-art-curriculum.md` | Look & Talk, hands-on art activity, artist/look study, materials |
| **Master / day plan** (any subject) | `content/curriculum/co-op/22-week-master-curriculum.md` | Full daily schedule + time blocks + Morning Binder routine — use for the "weekly structure" field |
