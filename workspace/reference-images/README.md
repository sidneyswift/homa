# Reference Images

Drop photos here for Homa to use when generating personalized materials (picture books, coloring pages, flash cards).

## Directories

- `children/` — Photos of your kids (used for character descriptions in books)
- `family/` — Family photos (for "about me" materials, family books)
- `pets-toys/` — Pets and favorite stuffed animals (characters in stories)

## Tips

- Clear, well-lit photos work best
- Multiple angles/outfits help with consistency
- Name the files descriptively (e.g., `emma-pool.jpg`, `mr-cow.jpg`)
- After adding photos, update `skills/picture-book/references/characters.md` with descriptions

## Privacy

These photos never leave your machine. They're passed to fal.ai for image generation but are not stored by the service.
