# Retired social starter pack

This directory is a historical asset archive from before the Quiet authority
identity. It is retained for migration forensics and is not an approved source
for social profiles, campaigns, or publication.

The files are not referenced by active marketing bundles. Do not upload them,
copy them into a new bundle, or use their palette or lockup geometry as a
design reference. The canonical source for current Homa identity projections
is `packages/design/src/contract/`, generated by `scripts/brand-assets.mts`.

`pnpm gen:socials` is intentionally fail-closed while this archive is retired.
A future replacement must be generated from the Quiet authority contract,
receive platform crop and accessibility evidence, and update the marketing
production manifest before this path can be reactivated.
