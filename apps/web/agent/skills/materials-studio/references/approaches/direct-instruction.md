# Direct Instruction (DISTAR) (all ages where DI curriculum is used)

- Scripted lessons. Every word the parent says should be written out if the family follows DI. Materials should include exact teaching scripts with parent text in one style and expected child responses in another.
- Sounds before letter names. DI teaches phoneme sounds first, never letter names. A letter page for a DI family focuses on the sound /m/, not "the letter M."
- Continuous blending, not segmenting. The child says the word slowly without pausing between sounds, then says it fast. Activities should practice blending (arrow-and-ball notation), not choppy sound-by-sound segmenting.
- Built-in error correction. Every task type should have a scripted correction procedure: "If the child says X, you say Y." The program anticipates failure and scripts the fix.
- Mastery before advancement. Do not progress to the next skill until the current one is solid. Progress checks are inline, not end-of-unit tests.
