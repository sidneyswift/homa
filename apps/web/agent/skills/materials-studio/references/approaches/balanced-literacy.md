# Balanced literacy (roughly ages 5 to 12)

- Story-as-hub weekly structure. One reading selection per week powers all ELA skill strands: phonics, spelling, vocabulary, grammar, writing, and cross-curricular extensions.
- 5-day arc within each week. Day 1: introduce (new story, new phonics pattern, spelling pretest). Day 2: practice (read selection, build words, introduce vocab). Day 3: generalize (reread for fluency, state spelling rules). Day 4: apply (comprehension practice, writing prompt). Day 5: assess (spelling post-test, fluency check, self-selected reading).
- Leveled differentiation available every day. Below-level, on-level, advanced, and ELL variants for every activity. The parent picks the right level, or the system recommends based on evidence.
- Cross-curricular centers extend the story theme. The week's reading selection drives science, social studies, art, and drama activities, not just ELA.
- Spiral review through Daily Language Practice. Sentence-level error correction that reviews ALL previous skills, not just the current week's focus.
