# Play-based / experiential (roughly ages 2 to 6)

- No worksheets for under-4s following play-based approaches. Activities should be hands-on: sensory bins, process art, STEM experiments, gross motor, dramatic play.
- Background knowledge over mastery. The goal is exposure and positive associations with learning, not testing. No assessments, no scores, no mastery expectations.
- Spiral skill development. The same 5-7 core skills (predicting, recall, sorting, number sense, measuring, shapes, alphabet) revisited with increasing complexity across units, not linear progression.
- Routine as scaffold. Predictable weekly rotation (e.g., Mon = predicting + sorting, Tue = letters + numbers) gives parent confidence. The schedule is the curriculum.
- Read-alouds as anchor. Every session starts with a themed book. Comprehension is built through questions, predictions, and retelling during the read-aloud, not on a worksheet.
