# Singapore Math (CPA progression) (roughly ages 4 to 12)

- Concrete → Pictorial → Abstract (CPA) is the law. Every math concept must progress through all three stages. PreK-K = full concrete (manipulatives). Grades 1-2 = pictorial (drawings, number bonds). Grades 3+ = abstract (equations).
- Number bonds are the core scaffold. From K through Grade 2, the part-whole relationship (number bonds circles) is how addition and subtraction are taught. Materials should include number bond diagrams.
- Three-tier scaffolding on every topic. Basics (guided, with worked examples) → Practice (independent, same difficulty) → Challenge (extension, higher difficulty). Every worksheet set should offer all three tiers.
- Model drawing (bar models) for word problems. From Grade 2 up, word problems are solved by drawing bar models to represent the relationships, not by guessing operations. Materials should include space for bar model drawing.
- Decreasing scaffolding across grades. PreK-K gets full-color, large white space, heavy visual support. By Grade 3-5: grayscale, denser layout, minimal illustration. The visual reduction is intentional, not lazy.
