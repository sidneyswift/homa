# Social narrative

Golden anchor: pass `anchorIds: ["social-narrative"]` to generate_image
so the output matches the Homa social narrative bar (illustration on
top, 2-3 big sentences below) for ages 3-8). Write your own prompt with
your own content; the anchor sets the visual bar, not the specifics.

First-person story format with illustration + text per page. Pattern:
normalize the emotion → describe body signals → state the goal → list
coping strategies → end with positive affirmation + open-ended question.

Great for: ages 3-8, social-emotional learning, anxiety management,
transition preparation (new school, new sibling), behavior support.
Used by occupational therapists, special education, and
social-emotional curricula.

Hybrid path for illustrated versions (generate_image for illustrations,
HTML for text). Packet recipe for multi-page assembly.

Design patterns (all binding for social-narrative):

- **Page structure**: illustration taking top 50-60% of page, text
  below in large, clear font (`font-size: 22px; line-height: 1.6;`).
- **6-8 pages total**: use packet recipe for assembly.
- **First person voice**: "Sometimes I feel...": the child is the
  narrator.
- **Simple sentences**: one idea per page. Maximum 2-3 sentences per
  page.
- **Story arc**: (1) normalize the emotion, (2) describe body signals
  ("my tummy feels tight"), (3) state the goal ("I want to feel
  calm"), (4-5) list 2-3 coping strategies with illustrations,
  (6) positive affirmation ("I can handle this"), (7-8) open-ended
  question for discussion ("What helps YOU feel calm?").
- **Warm color palette**: soft blues, greens, warm yellows. No harsh
  reds or high-contrast colors.
- **Illustration style**: gentle, reassuring. Characters with
  expressive but not exaggerated emotions.
