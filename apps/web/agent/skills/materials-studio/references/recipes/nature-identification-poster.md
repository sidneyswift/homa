# Nature identification poster

Golden anchor: pass `anchorIds: ["nature-identification-poster"]` to
generate_image so the output matches the Homa
nature-identification-poster bar (one elegant serif title with a thin
rule, a 3x4 grid of hairline-bordered cells, one large naturalistic
watercolor species per cell, a centered common-name label with a smaller
italic scientific name beneath, cream paper, grid running to the bottom
margin). Write your own prompt with your own content; the anchor sets
the visual bar, not the specifics.

A watercolor-style grid of 12+ species with labels. Reference-style
poster for nature study, designed to hang on a wall or slip into a
nature notebook.

Great for: ages 4-12, nature study (Charlotte Mason families especially),
science units on ecosystems, seasonal observation. Doubles as a
beautiful wall poster.

Hybrid path preferred (generate_image for watercolor species
illustrations, HTML for grid layout and labels). image-direct viable
for simpler versions with fewer species.

Design patterns (all binding for nature-identification-poster):

- **Grid layout**: 3×4 or 4×4 grid of species illustrations, each in
  a subtle bordered cell (`border: 1px solid #e0dcd6;`).
- **Common name label**: below each illustration, centered
  (`font-size: 14px; font-weight: 600;`).
- **Title**: at top in elegant serif or display type ("Backyard Birds",
  "Wildflowers of North America").
- **Optional habitat indicator**: small icon or colored dot per species
  showing habitat type.
- **Clean, field-guide aesthetic**: white or cream background, no
  cartoon style. Naturalistic watercolor or botanical illustration
  style.
- **Optional scientific names**: in italics below common name for
  older children.
