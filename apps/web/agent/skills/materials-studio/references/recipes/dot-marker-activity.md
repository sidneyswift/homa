# Dot-marker activity

Pages with large circles (1"+ diameter) for dot marker / bingo dauber
stamping. Letters, numbers, or shapes formed by circle arrangements
that toddlers fill in.

Great for: ages 2-4, letter recognition, number recognition, fine
motor development, color recognition. Perfect for the youngest
learners who cannot yet hold a pencil with precision.

Html path preferred for precise circle placement. image-direct viable
for heavily themed versions where illustrations dominate.

Design patterns (all binding for dot-marker-activity):

- **Large circles**: minimum 1 inch diameter (`width: 96px;
  height: 96px; border-radius: 50%; border: 3px solid var(--homa-ink);`).
- **Circle arrangement**: circles form the target letter/number/shape.
  Well-spaced so a toddler can stamp without precision.
- **Model at top**: the target letter/number/shape shown clearly at
  the top of the page as a reference (`font-size: 72px;
  font-weight: 700;`).
- **Maximum 15-20 circles per page**: more overwhelms the age group.
- **Background**: white or very light themed color. No busy patterns.
- **Instruction line**: simple, parent-readable: "Stamp each circle
  to make the letter A!" in small text at top.
- **No fine detail**: circles are the only interactive element.
  No tracing, no writing, no small shapes inside circles.
