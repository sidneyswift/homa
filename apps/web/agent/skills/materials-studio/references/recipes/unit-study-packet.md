# Unit study packet

**Golden anchor (binding):** pass `anchorIds: ["unit-study-packet"]` to generate_image so the output matches the Homa visual bar for this format. If the material teaches a topic with its own anchor (see the router Golden anchors table), ride that instead. Your prompt supplies the content; the anchor sets the bar.

A multi-page themed study bundle containing 8-12 different activity types
all centered on one topic. Uses the packet recipe (see "Packets: several
pages, one PDF" above) for assembly.

Template page order: cover → teacher guide → reference posters
(labeled/unlabeled/B&W) → info card → vocabulary list → letter tracing →
labeled diagram → blank labeling activity → cross-section diagram →
flow diagram → coloring page → cut-and-assemble craft → word search.

Great for: ages 4-10, unit studies, themed weeks, science and social
studies deep dives. The packet gives the parent a complete week of
materials on one topic.

Mixed paths: html for structure pages (vocab lists, letter tracing,
word search), hybrid for illustrated pages (posters, diagrams, coloring),
packet recipe for final assembly.

Design patterns (all binding for unit-study-packet):

- **Cover page**: large title, themed illustration (hybrid or
  image-direct), child's name field, topic subtitle.
- **Teacher guide**: parent-facing. Objectives, materials needed,
  suggested schedule, vocabulary list. Plain text, no decoration.
- **Resource page**: parent-facing list of books, videos, and reference
  material on the topic, one line each with a note on why. Field
  directive (2026-07-18): a unit study without a resource page leaves
  the parent doing the research Homa should have done.
- **Materials list**: everything the craft and activity pages need,
  gathered in one place, phrased for what the house already has. Cover
  every child who will use the packet, not just the oldest.
- **Consistent theming**: every page uses the same color accent, the
  same illustration style, and the same header format.
- **Each page is one activity type**: pull from materials-studio's
  existing recipes. A labeled-anatomy-diagram page follows that recipe;
  a word-search page follows the maze/puzzle recipe.
- **Page numbering**: bottom-center, small.
- **Difficulty progression**: easier activities first (coloring,
  tracing), harder activities later (labeling, word search).
