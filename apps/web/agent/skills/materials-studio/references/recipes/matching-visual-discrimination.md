# Matching / visual discrimination worksheet recipe

Golden anchor: pass `anchorIds: ["matching-visual-discrimination"]` to
generate_image so the output matches the Homa matching bar (large
friendly thick-outline illustrations, dot-to-dot matching columns,
clearly sectioned activities, a themed border, preschool-scale
spacing). Write your own prompt with your own content; the anchor
sets the visual bar, not the specifics.

(Design patterns below were extracted from Treasury of Year-Round
Preschool Activities, a multi-activity PK page.)

What it is: two columns of images where the child draws lines to match
pairs, OR rows of similar images where the child marks the different one.
Core visual discrimination skill for ages 3-6.

Design patterns from reference:
- Two distinct columns with generous spacing between them
- Dot markers between each image and the center gap (child draws line dot-to-dot)
- 4-6 pairs maximum: more overwhelms the age group
- Each image is a simple, recognizable cartoon with thick outlines
- Shuffled order on right column (never mirror the left ordering)
- For same/different variant: 3-4 items per row, one obviously different
- Cut-apart variant, two-piece puzzle cards: each pair prints as one card
  split by a wavy or zigzag cut line (compound word halves, equation and
  answer, word and picture). The mismatched cut is the self-check: wrong
  pairs visibly do not fit. Print on the heaviest stock the family has.
- Name/Date header at top

Creation paths:
- image-direct: best for themed matching (animals, objects) where
  illustrations carry the page
- hybrid: HTML for the column structure + dots + lines, image model for
  the individual illustrations
- html: only for abstract matching (letters, numbers, shapes) where
  text precision matters

For PK ages: keep images large (at least 1.5" per illustration), use
thick outlines suitable for coloring after matching, and limit to 4
pairs. The goal is visual scanning practice, not a memory test.
