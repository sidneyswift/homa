## Difficulty/Content Preferences

### Format Preferences
- *Foldables / interactive notebook inserts* — tactile, fold-and-glue formats that students physically construct. Not just worksheets.
- *Structured fill-in-the-blank outlines* — frameworks that break complex tasks (essay writing) into labeled sections with blank lines. Scaffolding over blank-page intimidation.
- *Hand-drawn doodle aesthetic* — sketchy, fun, hand-lettered look (think @mathdoodles). NOT clipart, NOT corporate/textbook clean. (Math/fun subjects)
- *Clean minimal black-and-white* — for writing/ELA, a stark, no-decoration approach works too. Structure IS the design. (Writing/analytical subjects)
- *Scaffolded versions* — blank (fill-in) → answer key → full color. Same layout, different levels of completion. Supports teach → practice → reference.
- *Difficulty differentiation* — same layout with more/fewer fields (e.g., 2-example vs 3-example body paragraphs) to serve different grade levels.
- *Color-coded by concept* — each operation/step gets its own distinct color. Makes abstract sequences visual and memorable.
- *Mnemonic anchoring* — visual + verbal memory aids (e.g., "Please Excuse My Dear Aunt Sally" with a cute sheep). Humor helps.
- *Practice embedded in the reference material* — not a separate worksheet. The foldable itself contains practice problems alongside the definitions.
- *Built-in instruction alongside the work* — left column defines what each section is, right column asks student to do it. Learn and apply simultaneously.
- *Print-friendly layouts* — designed for home/school printers. Landscape accordion folds (math) and portrait single-page (writing) both valued.

### Design Signals
- Big, bold bubble letters for key terms
- Doodle illustrations (gears, sheep, stars) — whimsical but not babyish
- Clear spatial hierarchy: definitions at top, practice at bottom
- Left-to-right flow cues with arrows
- Operation symbols (parentheses, ×, ÷, +, −) prominently displayed alongside letter mnemonics

## Curriculum Style Signals
- Order of Operations (PEMDAS) at 5th grade level — suggests ~grades 3-6 target range
- Five Paragraph Essay outline at secondary level (grades 7-10) — broader range than just elementary
- TEKS/Common Core aligned content valued (standards awareness)
- Foldable format suggests interactive notebook methodology — Charlotte Mason / eclectic leaning (hands-on, not textbook-driven)
- Structured writing process (outline → rough draft → final draft) — process-oriented, not one-shot assignments
- TPT as a source = comfortable with teacher-created resources, not just publisher curricula
- *Subject range expanding:* math (PEMDAS) + ELA/writing (essay structure) — not math-only
