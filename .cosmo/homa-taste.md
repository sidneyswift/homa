### Format Preferences
- *Foldables / interactive notebook inserts* — tactile, fold-and-glue formats that students physically construct. Not just worksheets.
- *Structured fill-in-the-blank outlines* — frameworks that break complex tasks (essay writing) into labeled sections with blank lines. Scaffolding over blank-page intimidation.
- *Hand-drawn doodle aesthetic* — sketchy, fun, hand-lettered look (think @mathdoodles). NOT clipart, NOT corporate/textbook clean. (Math/fun subjects)
- *Clean minimal black-and-white* — for writing/ELA, a stark, no-decoration approach works too. Structure IS the design. (Writing/analytical subjects)
- *Scaffolded versions* — blank (fill-in) → answer key → full color. Same layout, different levels of completion. Supports teach → practice → reference.
- *Difficulty differentiation* — same layout with more/fewer fields (e.g., 2-example vs 3-example body paragraphs) to serve different grade levels.
- *Color-coded by concept* — each operation/step gets its own distinct color. Makes abstract sequences visual and memorable.
- *Mnemonic anchoring* — visual + verbal memory aids (e.g., "Please Excuse My Dear Aunt Sally" with a cute sheep). Humor helps.
- *Practice embedded in the reference material* — not a separate worksheet. The foldable itself contains practice problems alongside the definitions.
- *Built-in instruction alongside the work* — left column defines what each section is, right column asks student to do it. Learn and apply simultaneously.
- *Gamified practice (maze/puzzle format)* — transforms rote drill into a navigation challenge. Correct answers advance through the maze; wrong answers hit dead ends. Self-checking without needing an answer key.
- *Notes + practice bundles* — guided notes page that teaches the concept, paired with an activity page that drills it. Teach → practice in one printable.
- *Progressive difficulty within a single page* — start with review of prerequisites, build to the new concept, end with tricky edge cases. Graduated on-ramp.
- *Cut-and-paste word work* — multi-sensory format: see the word → write the word → cut the tile → paste the tile. Four modalities for one concept. Tactile manipulation adds kinesthetic memory. Great for early learners and special ed.
- *Leveled progression systems* — same format, graduated difficulty (Level 1 → Level 2 → ...). Also works across a series (short a → short e → blends → digraphs). Systematic, not random.
- *Multi-representational number pages* — same number shown as digit (tracing/writing), word (coloring), quantity (color N stars), and structured model (ten frame). Builds number sense from four angles on one page.
- *Consistent template across a series* — same page layout for numbers 1-10. Child learns the format once, can work independently by page 3. Reduces cognitive load.
- *One-page foldable mini books* — single letter-size page with 8-panel grid that folds into a tiny book. Tactile construction (fold + cut) + reading in one. Great for social narratives, concept introductions, or any sequential content.
- *Social narratives ("social stories")* — first-person "I can..." format: normalize the emotion → describe body signals → list coping strategies → positive affirmation. Therapeutic format but useful for any child. Opens up SEL as a content category for Homa.
- *Dual-version (color + B&W)* — same content in full color (ready to use) and black & white (doubles as coloring activity). More engagement options from one design.
- *Diverse character representation* — multiple skin tones, hair types, and body types across illustrations. Inclusive by default.
- *Watercolor / hand-painted illustration style* — museum-quality anatomical watercolors, not clipart. Carolyng explicitly called out "love the art styles" — beautiful illustration elevates educational content. (Distinct from the hand-drawn doodle style — both are valued, for different contexts.)
- *Multi-activity unit study packets* — 12+ activity types centered on ONE topic (posters, info cards, labeling, tracing, coloring, crafts, word search). Gives the parent a complete mini-curriculum they can run for a week.
- *Cut-and-assemble crafts* — labeled cutout pieces the child colors, cuts, and physically reconstructs. Spatial reasoning + motor skills + content knowledge in one activity.
- *Dual art style within one product* — realistic watercolor for beauty/reference AND simplified cross-section for understanding/labeling. Different styles serve different pedagogical purposes.
- *Cross-curricular theme integration* — one theme (beach, worms, heart) woven through science, math, social studies, language arts, and art. Carolyng explicitly values "involvement of different disciplines and subjects through one theme."
- *Art history / art appreciation cards* — classic paintings connected to the unit theme (Van Gogh, Cassatt, Hokusai) with artist bios. Art as a discipline, not just decoration.
- *Morning basket pages* — dedicated Pre-K activity block (letter tracing, counting, sorting, mazes, puzzles) themed to the unit topic. Includes youngest learners in the family unit study.
- *Outdoor observation / field study* — guided real-world activity (dig for worms, measure with ruler, record data). Takes learning outside.
- *Lifecycle diagrams + cut-and-paste* — circular lifecycle illustration + cut-out images students arrange in correct order. Teaches process and sequence.
- *Parent customization hooks* — blank question worksheets for parents to write their own questions. Empowers the teaching parent.
- *3-part nomenclature cards (Montessori)* — watercolor illustration + label matching cards. Montessori methodology signal.
- *Art-as-math-manipulative* — watercolor illustrations cut out as circular counters for counting, sorting, comparing. Art doubles as math tools. Blank circles for child to draw their own.
- *Classification sorting mats* — T-chart activity (insect vs non-insect) where child physically sorts cut-out pieces. Hands-on classification.
- *Charlotte Mason nature journal pages* — mostly blank pages with watercolor corner illustrations. Space for child's own drawings and observations.
- *Visual schedule / daily rhythm cards* — illustrated cards (watercolor art + label) for structuring the homeschool day. Print, cut, hole-punch for ring or Velcro for chart. NOT academic content — learning infrastructure. 200+ cards covering routines, subjects, chores, outings, weather, time concepts.
- *Editable / customizable products* — editable option on daily rhythm cards. Parents want to personalize.
- *Print-friendly layouts* — designed for home/school printers. Landscape accordion folds (math) and portrait single-page (writing) both valued.
- *Interactivity built into the page itself* — puzzles (color-by-answer revealing a pattern), games (printable spinners with score tables), drawing tasks (dot-grid pattern continuation). These make math interactive using ONLY pencil/crayon and paper — no manipulatives, no household items, no prep. The page IS the engagement. Distinct from the manipulative-substitution preference — Carolyng wants BOTH options available. (Carolyng, 2026-07-18)
- *Reference-chart-then-exercise pattern* — a bordered reference box (with accent color) showing the grammar/concept form + explanation, followed immediately by varied exercises. The chart IS the lesson; the exercises are the practice. Both on the same page or in sequence. Student can look back at the chart when stuck. (Carolyng called this "the breakdown of reference and workplace.") (Carolyng, 2026-07-18)
- *Form → Meaning → Use progression* — teach what the structure LOOKS like (form), explain what it MEANS (rules/exceptions sidebar), then practice USING it in real contexts. Exercises should progress from controlled (one right answer) → guided (word bank) → free (student's own words). Model answer on first item always. (Carolyng, 2026-07-18)
- *Varied exercise types within one concept* — don't just give 20 identical fill-in-the-blanks. Mix transformation exercises, word-bank completion, contextual completion, and oral/discussion prompts. Modality shifts (written → oral) within the same page. (Carolyng, 2026-07-18)
- *Magazine-style reading pages* — real photographs (or high-quality AI-generated images), full-bleed imagery, text wrapping around images, vocabulary sidebars in colored boxes alongside the passage. Makes a workbook feel like a "real" publication. Visually captivating > visually sterile. (Carolyng, 2026-07-18)
- *Vocabulary sidebars inline with reading* — NOT a separate vocabulary page. Key words defined in colored boxes right where the child encounters them in the text. The child doesn't have to flip to a glossary or break reading flow. (Carolyng, 2026-07-18)
- *Spiral skill building across units* — each new reading/activity introduces ONE new skill while reinforcing previous ones through the content. Skills accumulate; content changes. The spiral is the architecture. (Carolyng, 2026-07-18)
- *Skill transfer via related passage* — after teaching a reading skill on one passage, provide a SECOND shorter passage on a related topic where the student applies the same skill independently. Proves comprehension transfer, not memorization. (Carolyng, 2026-07-18)
- *Challenge extension sections* — a dedicated "Challenge" block at the bottom of every math page that (a) stretches fast finishers with a harder problem type, and (b) teaches a meta-strategy (e.g., "use facts for 10 to derive nearby sums") rather than just more drill. Also serves as embedded diagnostic — reveals where the child actually is in their understanding. (Carolyng, 2026-07-18)
- *Resource page in unit studies* — curated book suggestions, reference materials, and video links for the topic. 3-5 picks, age-appropriate, quality-curated. Gives the parent a "go deeper" path without research. (Carolyng, 2026-07-18)
- *Materials list for crafts/activities* — upfront list of everything needed, appropriate for all children/students involved. Should flag per-age-group or per-activity requirements when the unit spans multiple grade levels. Eliminates mid-session scrambling. (Carolyng, 2026-07-18)

### Design Signals
- Big, bold bubble letters for key terms
- Doodle illustrations (gears, sheep, stars) — whimsical but not babyish
- Clear spatial hierarchy: definitions at top, practice at bottom
- Left-to-right flow cues with arrows
- Operation symbols (parentheses, ×, ÷, +, −) prominently displayed alongside letter mnemonics

- Foldable format suggests interactive notebook methodology — Charlotte Mason / eclectic leaning (hands-on, not textbook-driven)
- Structured writing process (outline → rough draft → final draft) — process-oriented, not one-shot assignments
- TPT as a source = comfortable with teacher-created resources, not just publisher curricula
- *Subject range expanding:* math (PEMDAS) + ELA/writing (essay structure) — not math-only
