### 2026-07-12 | Sid | TPT Free Download
**Source:** "FREE PEMDAS Foldable PDF" by Melanie Ellsworth / Science and Math Doodles (2017)
**What's valuable:** print-format | interactive-format | layout | skill-targeting
**Summary:**
A 25-page PDF containing a *foldable* (print-fold-glue interactive notebook insert) for Order of Operations (PEMDAS/GEMDAS/PBMDAS). 3 progression levels:

- *Blank version* — students fill in definitions + work practice problems by hand
- *Answer key version* — same layout with answers in red ink
- *Color version* — fully colored, each letter/operation gets its own color (red P, orange E, green M, teal D, blue A, purple S), yellow highlight strips, cute sheep mascot ("Please Excuse My Dear Aunt Sally")

*Format details:*
- Landscape orientation, printed double-sided, folded accordion-style
- Top row: large bubble letters (P, E, M, D, A, S) with operation symbols (parentheses, x³, ×, ÷, +, −)
- Bottom section: practice problems column + mnemonic chart + "Always work LEFT to RIGHT" reminder
- Back panel: decorative "Order of Operations" cover with gear doodles, glue-on-dots tab
- Hand-drawn doodle aesthetic (not clipart, not corporate clean)
- TEKS/Common Core alignment chart included

*Key design patterns:*
- Interactive/tactile: fold + glue + write = engagement
- Scaffolded: blank → filled → color versions serve different teaching moments
- Mnemonic anchoring: visual + verbal ("Please Excuse My Dear Aunt Sally" + sheep illustration)
- Color-coded operations: each step gets its own color, making the sequence visual
- Practice embedded IN the reference — not separate worksheet, the foldable itself has practice problems

**Status:** applied-to-full-flywheel

### 2026-07-12 | Sid | TPT Free Download
**Source:** "Five Paragraph Essay Outline" by The Daring English Teacher (2015)
**What's valuable:** layout | scaffolding | structure-teaching | writing-process
**Summary:**
An 8-page PDF with a structured essay outline worksheet. Two difficulty variants included:

- *2-example version* — each body paragraph has space for 2 examples + explanations
- *3-example version* — same layout but with 3 examples per body paragraph (more rigorous)

*Structure (both versions):*
- Header: Name / Date / Period / Essay Topic / Essay Title / Draft due dates
- I. Introduction: Attention Getter → Background Information → Thesis
- II–IV. Body Paragraphs 1–3: Topic Sentence → Examples + Explanations → Transition
- V. Conclusion: Restate Thesis → Final Thought

*Format details:*
- Clean, minimal black-and-white design — no doodles, no color, no clipart
- Two-column table layout: left column = what goes here (definitions/instructions), right column = blank lines for student writing
- Bold section headers with Roman numerals (I–V)
- Each section explicitly labels what's expected ("a. topic sentence", "b. information, examples, quotes...")
- Portrait orientation, print-ready

*Key design patterns:*
- *Scaffolded writing process* — breaks the intimidating "write an essay" into a clear 5-section fill-in-the-blank framework
- *Built-in instruction* — left column teaches what each part IS while the right column asks student to DO it. Learn and apply simultaneously.
- *Difficulty differentiation* — 2 vs 3 examples per paragraph = easy toggle for different grade levels or abilities
- *Process metadata* — rough draft due date + final draft due date fields reinforce writing-as-process, not one-shot
- *No visual flair* — stark contrast to the PEMDAS foldable. This is all structure, zero decoration. Suggests Sid values BOTH approaches.

**Status:** applied-to-full-flywheel

### 2026-07-17 | Sid | TPT Product
**Source:** "Short A CVC Words — Write, Cut & Paste Activity" by Adapting for Autism, Inc.
**What's valuable:** format-innovation | multi-sensory | leveled-progression | inclusive-design
**Summary:**
A cut-and-paste word work activity for short 'a' CVC words (cab, mad, bag, ham, pan, map). Part of a larger bundle covering the full phonics progression: CVC → Long Vowels → Word Families → Blends → Digraphs → Trigraphs → Diphthongs.

*Format:*
- Grid layout, one word per cell. Each cell contains: printed word (model), writing line (practice), and a cut-out tile at bottom.
- Student workflow: see the word → write the word → cut the tile → paste the tile. Four modalities reinforcing one word.
- Labeled "Level 1" — implies graduated difficulty tiers within each vowel.
- Airy spacing, generous cell size for developing handwriting. B&W, light ink.

*Key design patterns:*
- *Multi-sensory reinforcement:* visual (reading) + graphomotor (writing) + tactile (cutting/pasting) all for one word. Way more engagement than read-and-copy.
- *Model-then-do:* printed word is always visible as reference while the student writes and matches.
- *Leveled system:* Level 1 = 6 simple words. Implies Level 2+ adds complexity (more words, harder patterns). Scales within a consistent format.
- *Systematic phonics bundle:* short a → short e → short i → long vowels → blends → digraphs. The format is the constant; the content progresses.
- *Inclusive origin:* designed for autism/special ed but the multi-sensory approach is just good pedagogy for any early learner.

*New format type for Homa:*
- *Cut-and-paste word work* — we don't have a recipe for this. Combines handwriting practice + tactile tile manipulation in one printable.

**Status:** applied-to-full-flywheel

### 2026-07-17 | Sid | TPT Product
**Source:** "Two-Step Equations Notes & Maze Activity" by Gina Wilson / All Things Algebra (2012-2016)
**What's valuable:** format-innovation | scaffolding | gamification | self-checking
**Summary:**
A 3-page PDF containing two complementary components:

*Guided Notes (pages 1-2):*
- Cornell-style two-column layout: left column has topic categories, right column has worked examples with blanks
- Progressive difficulty: one-step equations (review) → fractions → two-step equations → "Watch Out!" edge cases
- 22 problems total across four difficulty tiers
- Fill-in-the-blank strategy cues ("To get rid of a fraction, multiply by the ___")
- Student header block: Name, Class, Date, Topic

*Maze Activity (page 3):*
- Grid-based maze: solve equation → follow correct answer → navigate from START to END
- 13 two-step equations embedded in maze cells
- Wrong answers = dead ends = instant self-checking
- "SHOW ALL STEPS" requirement enforces process
- Multiple answer options on paths (2-3 exits per cell) create low-stakes multiple-choice feel

*Key design patterns:*
- Teach-then-practice bundle: notes page introduces concept, maze page drills it. Single printable, two functions.
- Self-checking gamification: the maze structure replaces answer keys. If you're stuck, you went wrong somewhere.
- Progressive on-ramp: reviews prerequisites before the new concept — students warm up with one-step before tackling two-step.
- Edge case awareness: "Watch Out!" section specifically flags problems where you divide FIRST (coefficient before constant), breaking the default algorithm.
- Dense but organized: ~20% white space, heavy on content but spatial hierarchy keeps it navigable.
- B&W, light ink density — parent-printer friendly.

*New format types for Homa:*
- *Maze activity* — navigational puzzle tied to problem solutions. Not in Homa's recipe book yet.
- *Guided notes* — Cornell-style two-column notes with embedded practice. Different from the essay outline recipe.
