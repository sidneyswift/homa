# Weekly Plans

Homa drafts weekly plans based on child profiles, gap analysis, and recent lesson logs.

Plans are saved as `YYYY-WNN.md` (e.g., `2026-W20.md`).

Each plan includes:
- Priority subdomains to push (from weekly scoring)
- Strength to celebrate/extend
- Measurable goals for the week
- Suggested activities
- Parent's measurement protocol (5-10 min observation tasks)
