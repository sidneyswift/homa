# Copy-deck corpus: onboarding and paywall captures

Verbatim third-party copy captures from Mobbin and Appllama, taken 2026-08-31
for the mobile onboarding/paywall v2 plan
(`docs/homa-planning/plans/2026-08-30-mobile-onboarding-paywall-v2/`).
Each file is one app's full onboarding-to-paywall walk, named by its
App Store style slug (for example `cal-ai-calorie-tracker.md`); 50 apps total.

Captures are verbatim: third-party punctuation, casing, emoji, and em dashes
are preserved exactly as shipped, so this folder is a candidate for the
em-dash guard's `EXCLUDED_DIR_PREFIXES` list in `scripts/em-dash-check.mjs`
if it ever moves into the guard's scan scope. Do not "fix" quoted strings.

The comparison of this corpus against Homa's own deck lives in
[DELTA.md](DELTA.md).
