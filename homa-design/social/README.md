# HOMA, Social templates

Ready-to-use, on-brand social layouts at real export sizes. Open any file and Save-as-PDF or screenshot at 1× for a crisp asset. Swap copy freely; keep the wordmark, warm palette, and serif headlines.

- `post-tip.html`, 1080×1080 feed post ("Tip of the week").
- `quote-card.html`, 1080×1080 testimonial on dark espresso.
- `notification-moment.html`, 1080×1080 "She knows what Saturday is for", the suggestion as a lock-screen notification.
- `story-announcement.html`, 1080×1920 vertical story / reel cover.
- `carousel-cover.html`, 1080×1350 carousel cover ("3 ways"); duplicate for follow-on panels.
- `brand-promise.html`, 1080×1350 manifesto ("You've got this. I've got the rest.").

All use `styles.css` tokens + Google-hosted brand fonts. The handwritten Caveat accent appears once per layout, max.
