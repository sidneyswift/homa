# HOMA, Landing Page UI kit

Full marketing site recreation for HOMA.

**Sections:** sticky nav, hero (with a drop-in photo slot), feature grid, "how it works" steps, testimonial, pricing tiers, footer.

## Files
- `index.html`, entry; loads the bundle, Lucide, and the image-slot component.
- `LandingPage.jsx`, all sections (Nav, Hero, Features, HowItWorks, Quote, Pricing, Footer).
- `image-slot.js`, drag-and-drop photo placeholder for the hero.

Composes: Button, Card, Badge, Avatar, Icon. Uses the serif display face for headlines and the warm section band (`--bg-page-warm`) for rhythm.
